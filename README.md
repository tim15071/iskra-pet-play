# Моя Искра — поиграть

**Открыть игру:** https://tim15071.github.io/iskra-pet-play/

Браузерная версия игры с фирменным питомцем: уход, сон, украшения, «Небесный полёт» и «Найди пару». Работает на компьютере и планшете в браузере с WebGL 2. При первом запуске нужно дождаться загрузки игровой сцены.

Этот репозиторий содержит только готовую Web-сборку. Исходный проект разрабатывается отдельно в закрытом репозитории `tim15071/iskra-pet`.

Версия использует 2.5D: иллюстрированную комнату и состояния персонажа. Прогресс сохраняется на текущем устройстве и в текущем браузере. Игровые искры не связаны с деньгами или клиентским счётом.

Фирменные изображения и название принадлежат владельцу проекта и не предоставляются как свободные ассеты. Уведомления о сторонних компонентах находятся в `game/licenses/` и `licenses/`.
