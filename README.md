# Моя Искра — поиграть

**Открыть игру:** https://tim15071.github.io/iskra-pet-play/

**Установить на Android-планшет:** [тестовые APK на GitHub Releases](https://github.com/tim15071/iskra-pet-play/releases). Android 7.0+, OpenGL ES 3.0. При необходимости разрешить установку для браузера, которым скачан файл.

Версия 0.3.0: уход, сон, украшения, «Небесный полёт» и «Найди пару», десять глав приключения, три задания на день, сундук и подарки за уровни. Лунная комната и сад на облаке теперь отдельные локации. Потребности подписаны и ведут к действиям. В книге есть постоянная кнопка цели или награды, а «Твой мир» разделён на комнаты, наряды и сияние. Улучшены уведомления, выбор подарков и управление на планшете. Работает на компьютере и планшете в браузере с WebGL 2. При первом запуске нужно дождаться загрузки игровой сцены.

Этот репозиторий содержит только готовую Web-сборку. Исходный проект разрабатывается отдельно в закрытом репозитории `tim15071/iskra-pet`.

Версия использует 2.5D: иллюстрированную комнату и состояния персонажа. Прогресс сохраняется на текущем устройстве и в текущем браузере. Игровые искры не связаны с деньгами или клиентским счётом.
