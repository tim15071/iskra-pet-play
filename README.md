# Моя Искра — поиграть

**Открыть игру:** https://tim15071.github.io/iskra-pet-play/

**Установить на Android-планшет:** [тестовые APK на GitHub Releases](https://github.com/tim15071/iskra-pet-play/releases). Android 7.0+, OpenGL ES 3.0. При необходимости разрешить установку для браузера, которым скачан файл.

Версия 0.10.1: игровой пакет уменьшен с 39,7 до 17,2 МБ. Новый запуск с прогрессом сначала готовит проверенный кэш, затем открывает комнату; повторное открытие и офлайн-игра используют сохранённые файлы. Занятия «Вместе», шесть больших игр, семь комнат, 30 глав и прежний прогресс сохранены. WebGL 2, планшет и компьютер.

Этот репозиторий содержит только готовую Web-сборку. Исходный проект разрабатывается отдельно в закрытом репозитории `tim15071/iskra-pet`.

Версия использует измеренный 2D-риг персонажа и иллюстрированные комнаты. Прогресс сохраняется на текущем устройстве и в текущем браузере. Игровые искры не связаны с деньгами или клиентским счётом.

Фирменные изображения и название принадлежат владельцу проекта и не предоставляются как свободные ассеты. Уведомления о сторонних компонентах находятся в `game/licenses/` и `licenses/`.

Проба ref2game: [«Мастерская находок»](https://tim15071.github.io/iskra-pet-play/labs/iskra-find/index.html). Отдельная браузерная игра поиска с собственным сохранением. Основная игра и APK развиваются независимо.
