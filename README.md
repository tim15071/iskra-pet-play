# Моя Искра — поиграть

**Открыть игру:** https://tim15071.github.io/iskra-pet-play/

**Установить на Android-планшет:** [тестовые APK на GitHub Releases](https://github.com/tim15071/iskra-pet-play/releases). Android 7.0+, OpenGL ES 3.0. При необходимости разрешить установку для браузера, которым скачан файл.

Версия 0.7.0: «Маджонг Искры» с 12 решаемыми раскладками, свободными парами, подсказкой, перемешиванием и отменой. Фонарик звёзд и кристальный фонтан открываются на уровнях 20/24, ставятся в комнате и реагируют на касание. Всего пять игр, семь комнат, 26 глав и три задания на день. Старые покупки, сад, змейка и текущие задания сохраняются. Крупный каталог листается свайпом по обложкам и тексту; WebGL 2, планшет и компьютер.

Этот репозиторий содержит только готовую Web-сборку. Исходный проект разрабатывается отдельно в закрытом репозитории `tim15071/iskra-pet`.

Версия использует 2.5D: иллюстрированную комнату и состояния персонажа. Прогресс сохраняется на текущем устройстве и в текущем браузере. Игровые искры не связаны с деньгами или клиентским счётом.

Фирменные изображения и название принадлежат владельцу проекта и не предоставляются как свободные ассеты. Уведомления о сторонних компонентах находятся в `game/licenses/` и `licenses/`.
